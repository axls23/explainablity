# Chronoscope Console Output Interpretation Guide

This guide explains how to interpret the console output generated by Chronoscope during experiments. All output is displayed via Rich Console formatting for readability.

---

## Quick Reference: What Each Output Means

### Model Loading Phase

```
Loading model: Qwen/Qwen2.5-0.5B...
[OK] Model loaded on cuda
AUTO-DETECTED: 12 attention heads (configured: 12)
AUTO-DETECTED: 1024 hidden dimension (configured: 1024)
```

**How to interpret:**
- `cuda` = GPU acceleration enabled (faster); `cpu` = CPU only (slower but works)
- Auto-detected values should match your model's architecture
- Mismatch warnings indicate config needs adjustment

### Step 1: Capturing Trajectory

```
Step 1: Capturing reasoning trajectory...
Token generation: ████████████ 100%
  Tokens generated: 128
```

**What's happening:** The model generates text while the Interceptor captures the residual stream at each layer.

**How to interpret:**
- Progress bar shows generation progress
- Token count indicates the length of the reasoning trace analyzed

---

### Step 2: SVD Compression

```
Step 2: Compressing trajectory via SVD...
  Components: 8
  Explained variance captured
```

**What's happening:** High-dimensional activations (e.g., 1024D) are compressed to tractable time series (e.g., 8 principal components).

**How to interpret:**
- PC0 = Primary trend component (main reasoning direction)
- PC1, PC2 = Secondary variations
- Higher components = finer details/noise

---

### Step 3: Signal Decomposition

```
Step 3: Decomposing signal into components...
  Trend: Long-term drift in reasoning state
  Seasonal: Periodic patterns (if any)
  Residual: Unexplained noise
  Detected period: X tokens
```

**How to interpret:**
| Component | Meaning | What to Look For |
|-----------|---------|------------------|
| **Trend** | Overall reasoning direction | Smooth = stable reasoning; Erratic = confused |
| **Seasonal** | Repeating patterns | Indicates cyclical reasoning (e.g., "step 1, step 2, step 3") |
| **Residual** | Unexplained variance | High residual = complex/unpredictable reasoning |
| **Detected period** | Cycle length | E.g., period=5 means pattern repeats every 5 tokens |

---

### Step 4: Spectral Analysis

```
Step 4: Spectral analysis...
  Dominant frequency: 0.125 cycles/token
  Spectral entropy: 2.34
```

**What's happening:** FFT transforms the signal into frequency domain.

**How to interpret:**
- **Dominant frequency:** Main oscillation rate (e.g., 0.125 = cycle every 8 tokens)
- **Spectral entropy:**
  - Low (<1.5) = focused, periodic reasoning
  - High (>3.0) = scattered, noisy reasoning

---

### Step 5: Stationarity Tests

```
Step 5: Testing stationarity...
  ADF p-value (PC0): 0.032
  KPSS p-value (PC0): 0.150
  Diagnosis: STATIONARY
```

**What's happening:** Statistical tests determine if the reasoning trace has stable properties over time.

**How to interpret the 4-way diagnosis:**

| ADF p-value | KPSS p-value | Diagnosis | Meaning |
|-------------|--------------|-----------|---------|
| <0.05 | >0.05 | **STATIONARY** | Stable reasoning process |
| >0.05 | <0.05 | **UNIT_ROOT** | Trending/wandering reasoning |
| <0.05 | <0.05 | **STRUCTURAL_CHANGE** | Possible regime shift or non-linear dynamics (contradictory test results) |
| >0.05 | >0.05 | **AMBIGUOUS** | Inconclusive (short trace or complex dynamics) |

> **Note:** The "STRUCTURAL_CHANGE" diagnosis indicates contradictory evidence: ADF rejects unit root while KPSS rejects stationarity. This typically suggests regime shifts, structural breaks, or non-linear trends rather than fractional integration.

**Why it matters:** Non-stationary traces require differencing before VAR analysis.

---

### Step 6: Activation Patching (Sensitivity Analysis)

```
Step 6: Running causal patching sweep...
  Layers: 24 × Tokens: 64
  Patching: ████████████ 100%
```

**What's happening:** Systematically zeros out activations at each (layer, token) position to measure sensitivity of the output trajectory.

**How to interpret:**
- High divergence = that (layer, token) position has high influence on the trajectory
- Results feed into the influence heatmap

> **Note:** This measures *sensitivity* and *attribution*, not Pearlian causation. In neural networks, activation ablation violates modularity assumptions, so results indicate importance rather than mechanistic causal effects.

---

### Step 7: Head Interaction Analysis (VAR)

```
Step 7: Estimating head interactions via VAR...
  Selected lag order: 3 (BIC)
  Significant pairs: 12/144 (FDR α=0.05)
  Joint stationarity checked: True
  Non-stationary channels: 2/12
  Selective differencing applied: True
  Johansen cointegration rank: 1
```

**What's happening:** Vector Autoregression models temporal dependencies between attention heads (Granger predictive relationships).

**How to interpret:**

| Metric | Meaning | Good Values |
|--------|---------|-------------|
| **Lag order** | How many past tokens influence current | 2-5 typical |
| **Significant pairs** | Causal connections surviving FDR correction | More = richer head interaction |
| **Non-stationary channels** | Heads needing differencing | Fewer = more stable |
| **Cointegration rank** | Long-run equilibrium relationships | 0 = none; >0 = shared trends |

### Step 8: Validity Score Breakdown

```
Step 8: Computing composite validity score...
  DTW Sensitivity: 0.7234
  Spectral Coherence: 0.8156
  Topological Smoothness: 0.6891
  Active Reasoning: 0.7542
  Composite: 0.7456
  Verdict: STRONG REASONING
```

**What's happening:** Multiple metrics combine into a single validity score.

**How to interpret each component:**

| Metric | Range | What It Measures | Good Values |
|--------|-------|------------------|-------------|
| **DTW Sensitivity** | 0-1 | Trajectory sensitivity to interventions | >0.6 = responsive to patching |
| **Spectral Coherence** | 0-1 | Frequency-domain stability | >0.7 = consistent oscillations |
| **Topological Smoothness** | 0-1 | Manifold continuity (TDA-based) | >0.6 = smooth reasoning path |
| **Active Reasoning** | 0-1 | Entropy/engagement level | >0.5 = active computation |
| **Composite** | 0-1 | Weighted average | See verdict below |

**Verdict thresholds:**

| Composite Score | Verdict | Meaning |
|-----------------|---------|---------|
| ≥0.75 | **DYNAMIC REASONING** | High dynamism, coherent trajectory |
| 0.50-0.75 | **MODERATE DYNAMICS** | Acceptable, review suggested |
| 0.30-0.50 | **LOW DYNAMICS** | Low confidence, verify output |
| <0.30 | **STATIC MODE** | Model may be in recall/recitation mode |

> **Important Caveats:**
> - This score measures trajectory dynamics, NOT factual correctness
> - Weights are arbitrary and should be calibrated on labeled data
> - Topological smoothness is an experimental hypothesis (unvalidated)

## Dashboard Panel Interpretation

When running with the live dashboard, 12 panels stream real-time:

### 1. State Panel
```
Hurst: 0.72 | ADF: 0.03 | VECM: Yes | Phase: EXPLORATION
```
- **Hurst >0.5** = long-range dependence (trending); **<0.5** = mean-reverting (experimental metric)
- **ADF <0.05** = stationary
- **VECM** = cointegration detected (long-run relationships exist)
- **Phase** = current HMM-discovered reasoning mode

> **Note:** Hurst exponent interpretation for LLM activations is experimental. These are deterministic trajectories, not stochastic processes, so standard Hurst interpretations apply differently.

### 2. Entropy Chart (14 lines)
- Each line = one attention head's entropy over time
- **Spikes** = head is "thinking hard" at that token
- **Flat lines** = head is idle or saturated

### 3. VAR Matrix (14×14 heatmap)
- Rows = source heads; Columns = target heads
- **Bright cells** = strong causal influence
- Look for: Which heads drive others?

### 4. Composite Verdict (Ring)
- 0-100 score with color coding
- **Green** = strong; **Yellow** = moderate; **Red** = weak

### 5. VAR Influence List (Bar chart)
- Top causal pairs ranked by influence strength
- Answers: "Which head pairs matter most?"

### 6. Perturbation Results
- Head knockout experiment results
- **High restoration score** = head is critical for output quality

### 7. TDA Panel
```
H0: 3 components | H1: 2 loops | Euler: 1
```
- **H0** = connected components (β₀)
- **H1** = 1D loop structures (β₁)
- **Euler characteristic** = β₀ - β₁ (topological invariant)

> **Experimental Feature:** The relationship between Betti numbers and reasoning quality is an unvalidated hypothesis. High Betti numbers may result from noise or sampling density, not necessarily reasoning anomalies.

### 8. Signal Quality (5 metrics)
Per-head diagnostics:
- Stationarity (ADF p-value)
- Variance
- Entropy rate
- Change energy
- Regime shift flag

### 9. HMM Phase
- Current reasoning phase (e.g., "EXPLORATION", "CONSOLIDATION", "CONVERGENCE")

### 10. Phase Timeline
- Visual sequence of phases over token positions
- Shows reasoning "chapters"

### 11. System Log
- Classified event stream (e.g., "Regime shift detected at token 42")

### 12. Chat Island
- Interactive prompt input for live experiments

### Pattern 1: "Clean" Reasoning
```
Hurst: 0.75 | ADF: 0.02 | Spectral: 0.85 | Verdict: STRONG
```
- **Interpretation:** Model is reasoning systematically with stable dynamics

### Pattern 2: "Wandering" Reasoning
```
Hurst: 0.45 | ADF: 0.45 | KPSS: 0.02 | Verdict: MODERATE
```
- **Interpretation:** Unit root detected; reasoning drifts without settling

### Pattern 3: "Recall" Mode (Not Reasoning)
```
Hurst: 0.50 | Active Reasoning: 0.15 | Verdict: NO REASONING
```
- **Interpretation:** Low engagement; model is likely recalling memorized text

### Pattern 4: "Complex Multi-Phase" Reasoning
```
H0: 5 | H1: 3 | Phases: [EXPLORATION → ANALYSIS → SYNTHESIS]
```
- **Interpretation:** Rich topological structure with distinct reasoning stages

## Troubleshooting via Console Output

### "No Reasoning Detected"
**Possible causes:**
- Prompt is too simple (model recalls rather than reasons)
- Trace too short (<20 tokens)
- Model is under-loaded (try larger model)

**Fix:** Use more complex prompts requiring multi-step reasoning

### "AMBIGUOUS" Stationarity
**Possible causes:**
- Trace is too short for statistical tests
- Genuine complex dynamics

**Fix:** Increase `max_new_tokens` in config

### VAR Fails to Converge
**Possible causes:**
- Too many parameters for trace length
- Non-stationary data not differenced

**Fix:** Check "Selective differencing applied" message; if False, enable `use_selective_diff=True` in config

## Summary: Quick Decision Tree

```
1. Check Verdict first
   ├─ STRONG → Trust the output, review heatmaps for insights
   ├─ MODERATE → Output is usable but verify key claims
   └─ WEAK/NONE → Do not trust; model likely recalling

2. Check Hurst exponent
   ├─ >0.7 → Persistent, trending reasoning
   ├─ 0.3-0.7 → Balanced
   └─ <0.3 → Mean-reverting, scattered

3. Check Active Reasoning score
   ├─ >0.6 → Model is "engaged"
   └─ <0.3 → Model is on autopilot

4. Check TDA (H0, H1)
   ├─ H0 > 1 → Multiple reasoning clusters (multi-faceted analysis)
   └─ H1 > 0 → Cyclic reasoning patterns detected
```
